# Техдолг

- Битая ссылка на оригинале: `/menu_abriсosovo` (русская «с») отдаёт 404 – на копии ведёт на balance-fit.ru, как и было.
- Рантайм Тильды сам дозагружает мелкие файлы с static.tildacdn.com (tilda-zero-form-errorbox.min.css, маска телефона,
  tilda-errors) – адрес зашит в их JS. Копия от CDN Тильды полностью не отвязана.
- Телефон в шапке на оригинале подменяет Calltouch (коллтрекинг); на копии Calltouch вырезан – виден постоянный номер из разметки.
- Ошибка JS «Cannot read properties of null (reading 'classList')» на /imperial – есть и на оригинале.
- Личные кабинеты (/lk, /lk_abricosovo, /lk_admiral – виджет mobifitness; /lkabrikosovo – reservi.ru) на копии не рисуются
  (виджеты привязаны к домену клиента): на месте кабинета пусто. Решение владельца: оставить, заменить ссылкой на живой ЛК или
  подключить на своём домене.
- Яндекс-карты на /contacts* дают ошибку `__provideBundle` только на копии (ключ API карт, вероятно, ограничен доменом balance-fit.ru).
- robots.txt в подпапке /balance-fit/ поисковики не читают; страницы закрыты meta robots noindex, файлы в /_t/ – нет.
- Ссылка `data-field-formmsgurl-value="/thanks_day"` на /day: страница «спасибо» не перенесена (срабатывает только после
  отправки, а отправка отключена).
